# Support

For bugs, compatibility problems, or feature requests, open an issue in:

https://github.com/imMamdouhaboammar/skill-conductor/issues

Include:

- Skill Conductor version or commit
- target host and surface
- the relevant skill/package structure
- expected behavior
- observed behavior
- reproducible eval case when possible

Do not include API keys, access tokens, private repository content, or other secrets in public issues.
