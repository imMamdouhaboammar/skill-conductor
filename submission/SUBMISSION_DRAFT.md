## Public listing draft

**Display name**

Skill Conductor

**Short description**

Design and test agent Skills

**Long description**

Skill Conductor turns a task, workflow, prompt, SOP, runbook, or existing Skill into a behaviorally specified agent Skill. It defines activation and negative-trigger boundaries, chooses architecture before prose, calibrates freedom by consequence, separates portable behavior from host-specific adapters, creates evidence-based evaluation coverage, pressure-tests brittle rules, controls regressions with held-out cases, and prepares Skill packages without presenting unexecuted checks as passed. The Plugin is Skills-only and its core workflow does not require an external app or MCP server.

## Skill description

Design, create, improve, evaluate, port, review, and package agent Skills. Use when a user wants to teach an agent a repeatable workflow, convert a prompt/SOP/runbook into a Skill, fix unreliable Skill activation or behavior, test a Skill, compare Skill versions, make a Skill portable across ChatGPT/Codex/Claude or another agent host, or prepare a Skill for distribution, even when they do not explicitly say "Skill". Do NOT use for merely executing an already-installed Skill or for unrelated general coding.
